# 🚀 Next.js Project

This is a modern web application built with **Next.js**, initialized using `create-next-app`.

---

## 🛠️ Getting Started

To run the project locally, start the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Once the server is running, open your browser and visit:

👉 http://localhost:3000

The app will automatically reload as you make changes.

---

## ✏️ Development

You can begin editing the main page here:

```
app/page.tsx
```

Changes will reflect instantly thanks to Next.js hot reloading.

---

## 🎨 Fonts & Optimization

This project uses **next/font** to automatically optimize and load the **Geist** font family, ensuring better performance and consistent typography.
